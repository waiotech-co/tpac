# Glossary

| English | فارسی | Meaning |
|---|---|---|
| Plant | تصفیه‌خانه | One treatment plant operated as one site (01 M-1) |
| Plant code | کد تصفیه‌خانه | Four characters identifying a plant (02 §3) |
| Unit | واحد | A physical area of a plant identified by its primary function (01 M-3) |
| Unit type | نوع واحد | An entry of the unit catalogue |
| Instance | شماره واحد | The number of a unit among units of the same type |
| Unit map | نقشه واحدها | The site plan marking every unit's boundary (01 M-4) |
| Position | جایگاه | A place where a maintainable thing is installed, or a maintained structure (01 M-7) |
| Equipment position | جایگاه تجهیز | A position directly under a unit (01 M-8) |
| Component position | جایگاه جزء | A position under another position (01 M-8) |
| Structure position | جایگاه سازه | A position of a structure kind; carries a civil class (01 M-10) |
| Population position | جایگاه گروهی | A position standing for identical small items, with a quantity (01 M-11) |
| Kind | نوع جایگاه | The role of a position, from the kind catalogue (01 M-17) |
| Index | شماره | The number of a position among siblings of the same kind (02 §4) |
| Position code | کد جایگاه | The address of a position (02) |
| Asset | دارایی فیزیکی | A physical object with its own history (01 M-12) |
| Asset number | شماره دارایی | The identifier of an asset (02 §7) |
| Installation | نصب | The time-bounded relation between an asset and a position (01 M-13) |
| Classification | طبقه‌بندی | Group, class and type of an asset (01 M-18) |
| Group | گروه | The broad technical family of a class |
| Class | کلاس | An equipment family |
| Type | تیپ | A working principle within a class |
| Serving test | آزمون خدمت‌رسانی | The rule deciding whether a thing is a child of a position (03 P5.1) |
| Building services | تأسیسات ساختمان | Things that exist for a building and are children of it (03 P5.5) |
| Package | پکیج | A skid or system supplied and operated as one unit (03 P5.6) |
| Legacy code | کد قبلی | A code from an earlier scheme, kept on the position it identified (05 L-9) |
| Retired | بازنشسته | No longer in use; code and number never reissued (05 L-6) |
| Compact form | شکل فشرده | A code without separators |
| Written form | شکل نوشتاری | A code written without separators, the only form TPAC uses |
